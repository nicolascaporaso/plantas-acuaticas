Musgo de Java (Taxiphyllum barbieri): ficha técnica y cuidados

Musgo de Java (Taxiphyllum barbieri): ficha técnica y cuidados, luz baja a media, temperatura 15 - 28 °C, pH 5.5 - 8.0, CO2 no necesario, reproducción, acuario plantado.

Descripción general

Musgo de Java (Taxiphyllum barbieri) es una planta acuática originaria de Sudeste Asiático de dificultad muy fácil y crecimiento lento a moderado, muy usada en acuarios plantados.

Ficha técnica

Datos botánicos

  • Nombre común: Musgo de Java
  • Nombre científico: Taxiphyllum barbieri
  • Familia: Hypnaceae
  • Origen: Sudeste Asiático
  • Dificultad: Muy Fácil

Tamaño y crecimiento

  • Altura: 3 - 10 cm (alfombra o volumen)
  • Ancho: Expansivo
  • Velocidad de crecimiento: Lento a Moderado
  • Tipo de crecimiento: Musgo / Epífito
  • Ubicación recomendada: Troncos, rocas, suelos o paredes de malla

Parámetros de cultivo

Agua y luz

  • Temperatura: 15 - 28 °C
  • pH: 5.5 - 8.0
  • GH / KH: Amplio rango
  • Iluminación: Baja a Media
  • CO2: No necesario

Nutrientes y sistema

  • Fertilización: Abono líquido general mínimo
  • Uso en low-tech / high-tech: Estelar en sistemas Low-Tech.
  • Uso en acuarios de agua fría: Resiste muy bien el agua fría.

Manejo en el acuario

Cómo plantarla

Atar con hilo transparente o malla sobre maderas y rocas; se adhiere sola con el tiempo.

Cómo reproducirla

Por fragmentación y división de manojos.

Problemas frecuentes

Acumulación de detritos y suciedad en su interior si no hay buena corriente.

Algas asociadas

Muy susceptible a algas filamentosas si hay desequilibrios de luz/nutrientes.

Compatibilidad y uso

Compatibilidad con peces

Perfecto; resguarda a peces pequeños y alevines.

Compatibilidad con gambas

El hábitat preferido por excelencia para gambas y crías.

Recursos relacionados

Plantas similares

  • Vesicularia reticulata
  • Riccia fluitans
